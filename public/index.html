📝 如何获取 Session Key：

  1. 在浏览器中登录 claude.ai
  2. 按 F12 打开开发者工具
  3. 切换到 Application 标签
  4. 左侧展开 Cookies → https://claude.ai
  5. 找到名为 sessionKey 的条目
  6. 双击 Value 列复制值，粘贴到上方输入框

⚠️ Session Key 通常几天~两周过期，需定期更新
